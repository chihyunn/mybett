# Feature Specification: Sports Quant Betting Control System

**Feature Branch**: `001-sports-quant-betting`
**Created**: 2026-01-20
**Status**: Draft
**Input**: User description: "누적 수익 $0에서 발란스$5000 시작하여 내 에이전트와 시장의 확률 괴리(Edge)를 실시간 계산하고, 에지 크기에 따른 동적 베팅 추천(5~10%→$200, 10%+→$350) 및 팀별 '예측 에지 vs 실현 에지'의 과학적 오차를 분석하는 NBA 퀀트 관제 시스템"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 예측 입력 (Priority: P1)

사용자가 스포츠 타입(NBA/NHL/MLB)을 선택하고, **팀A vs 팀B 매치업**을 구성한 후, 베팅 대상 팀(A 또는 B)과 베팅 타입(+핸디캡, -핸디캡, 오버, 언더)을 선택하여 내 에이전트의 승리확률(0.xx)과 시장 확률(0.xx)을 입력하면 시스템이 Edge를 계산해준다.

**Why this priority**: 전체 시스템의 핵심 기능이며, Edge 계산 없이는 베팅 추천과 분석이 불가능함

**Independent Test**: 스포츠/매치업/베팅타입 선택 후 확률 입력만으로 Edge 값이 화면에 표시되는지 확인 가능

**Acceptance Scenarios**:

1. **Given** 사용자가 시스템에 접속한 상태, **When** NBA를 선택하고 Lakers vs Celtics 매치업을 구성하고 Lakers +핸디캡을 선택 후 에이전트 확률 0.65, 시장 확률 0.55를 입력, **Then** Edge 10%가 계산되어 표시됨
2. **Given** 스포츠 타입이 선택된 상태, **When** 팀A, 팀B 드롭다운 요청, **Then** 해당 스포츠의 모든 팀이 각각 리스트로 표시됨
3. **Given** 팀A와 팀B가 동일한 팀으로 선택됨, **When** 매치업 확정 시도, **Then** "같은 팀끼리 매치업 불가" 오류 메시지 표시
4. **Given** 확률 입력 화면, **When** 에이전트 확률이나 시장 확률이 0~1 범위를 벗어남, **Then** 유효성 오류 메시지 표시

---

### User Story 2 - 동적 베팅 추천 (Priority: P1)

Edge가 계산된 후, 시스템은 Edge 크기에 따라 동적으로 베팅 금액을 추천한다. Edge 5~10%는 $200, 10% 이상은 $350으로 차등 추천한다.

**Why this priority**: 베팅 의사결정의 핵심 가치 제공, 예측과 함께 즉시 필요한 기능

**Independent Test**: Edge 값에 따라 정확한 베팅 금액이 추천되는지 확인 가능

**Acceptance Scenarios**:

1. **Given** Edge가 7%로 계산된 상태, **When** 베팅 추천 요청, **Then** $200 베팅 추천
2. **Given** Edge가 12%로 계산된 상태, **When** 베팅 추천 요청, **Then** $350 베팅 추천
3. **Given** Edge가 5% 미만인 상태, **When** 베팅 추천 요청, **Then** "베팅 비추천" 메시지 표시
4. **Given** Edge가 8%이고 밸런스가 $150인 상태, **When** 베팅 추천 요청, **Then** $150 베팅 추천 (가용 금액)

---

### User Story 3 - 결과 입력 및 기록 (Priority: P2)

사용자가 베팅 결과(승리/패배)와 **실제 베팅 금액**을 입력하면, 시스템은 해당 베팅을 기록하고 누적 수익과 밸런스를 업데이트한다.

**Why this priority**: 성과 추적과 에지 분석의 기반 데이터

**Independent Test**: 결과 입력 후 밸런스 변화와 기록 저장 확인 가능

**Acceptance Scenarios**:

1. **Given** 베팅 금액 $200이 추천된 상태, **When** 사용자가 "승리"를 입력, **Then** 밸런스에 수익이 추가되고 기록 저장
2. **Given** 베팅 금액 $200이 추천된 상태, **When** 사용자가 "패배"를 입력, **Then** 밸런스에서 베팅금액 차감되고 기록 저장
3. **Given** 결과 입력 완료, **When** 대시보드 확인, **Then** 누적 수익과 현재 밸런스가 정확히 표시됨

---

### User Story 4 - 예측 에지 vs 실현 에지 분석 (Priority: P2)

시스템은 **팀별** 및 **전체 포트폴리오** 수준에서 예측한 Edge(Δp)와 실제 결과 기반 실현 Edge(Δr)의 과학적 오차를 분석하여 보여준다.

**핵심 공식**:
- 예측 에지: `Δp = P_agent - P_market` (베팅 진입 시점)
- 실현 에지: `Δr = Result(1 or 0) - P_market` (경기 종료 후)
- 오차: `Error = Δp - Δr` (에이전트 과대/과소평가 정도)

**Why this priority**: 에이전트 정확도 검증 및 개선을 위한 핵심 분석. 어느 팀에서 에이전트가 과대평가/과소평가하는지 파악 가능.

**Independent Test**: 충분한 베팅 기록 축적 후 팀별/전체 예측 vs 실현 에지 비교표 확인 가능

**Acceptance Scenarios**:

1. **Given** Lakers 팀에 대해 10회 이상 베팅 기록이 있음, **When** 팀별 에지 분석 요청, **Then** Lakers의 평균 Δp, 평균 Δr, 오차(Δp - Δr), 베팅수가 표시됨
2. **Given** 전체 베팅 기록이 10회 이상 있음, **When** 전체 포트폴리오 분석 요청, **Then** 전체 평균 Δp, 전체 평균 Δr, 전체 오차, 총 베팅수가 표시됨
3. **Given** 팀별 분석 화면, **When** 스포츠별 필터 적용, **Then** 해당 스포츠의 팀별 에지 분석만 표시됨

---

### User Story 5 - 밸런스 및 수익 대시보드 (Priority: P3)

사용자는 시작 밸런스 $5,000에서 출발하여 누적 수익 $0부터의 성과를 대시보드에서 추적할 수 있다.

**Why this priority**: 전체 성과 모니터링, 핵심 기능 완성 후 필요

**Independent Test**: 대시보드에서 밸런스, 누적 수익, 총 베팅 횟수 확인 가능

**Acceptance Scenarios**:

1. **Given** 시스템 최초 접속, **When** 대시보드 확인, **Then** 시작 밸런스 $5,000, 누적 수익 $0 표시
2. **Given** 여러 베팅 기록이 있는 상태, **When** 대시보드 확인, **Then** 현재 밸런스, 누적 수익, 총 베팅 횟수, 승률이 표시됨

---

### Edge Cases

- 확률 입력 시 0 또는 1 정확히 입력하면? → 유효값으로 처리 (0%~100% Edge 가능)
- 밸런스가 추천 베팅 금액보다 적으면? → 가용 금액 내 베팅 추천 (예: 밸런스 $150이면 $150 추천)
- 동일 경기에 중복 베팅 입력하면? → 허용 (같은 팀 다른 베팅타입 가능)
- 시장 확률과 에이전트 확률이 동일하면? → Edge 0%, 베팅 비추천
- 에이전트 확률이 시장 확률보다 낮으면? → 음수 Edge 표시, 베팅 강력 비추천

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템 MUST 스포츠 타입(NBA, NHL, MLB) 선택 기능 제공
- **FR-002**: 시스템 MUST 선택된 스포츠 타입에 따른 팀A, 팀B 선택 기능 제공 (매치업 구성)
- **FR-002a**: 시스템 MUST 팀A와 팀B가 동일할 경우 오류 처리
- **FR-003**: 시스템 MUST 베팅 타입(+핸디캡, -핸디캡, 오버, 언더) 선택 기능 제공
- **FR-003a**: 시스템 MUST 베팅 대상 팀(A 또는 B) 선택 기능 제공
- **FR-004**: 사용자 MUST 에이전트 승리확률(0.00~1.00)을 입력할 수 있어야 함
- **FR-005**: 사용자 MUST 시장 확률(0.00~1.00)을 입력할 수 있어야 함
- **FR-006**: 시스템 MUST 예측 에지(Δp)를 자동 계산하여 표시 (Δp = P_agent - P_market)
- **FR-007**: 시스템 MUST Edge 크기에 따라 동적 베팅 금액 추천 (5~10%→$200, 10%+→$350)
- **FR-007a**: 시스템 MUST 밸런스가 추천 금액보다 적을 경우 가용 금액 내에서 베팅 추천
- **FR-008**: 시스템 MUST Edge 5% 미만일 때 베팅 비추천 메시지 표시
- **FR-009**: 사용자 MUST 베팅 결과(승리/패배)와 실제 베팅 금액을 입력할 수 있어야 함
- **FR-010**: 시스템 MUST 결과에 따라 밸런스와 누적 수익 자동 업데이트
- **FR-011**: 시스템 MUST 모든 베팅 기록을 저장 (스포츠, 팀A, 팀B, 베팅대상팀, 베팅타입, 확률, Edge, 금액, 결과)
- **FR-012**: 시스템 MUST 결과 입력 시 실현 에지(Δr) 자동 계산 (Δr = Result(1 or 0) - P_market)
- **FR-016**: 시스템 MUST 팀별 에지 분석 제공 (평균 Δp, 평균 Δr, 오차, 베팅수)
- **FR-017**: 시스템 MUST 전체 포트폴리오 에지 분석 제공 (전체 평균 Δp, 전체 평균 Δr, 전체 오차)
- **FR-018**: 시스템 MUST 베팅타입별 에지 분석 제공 (+핸/-핸/오버/언더별 정확도)
- **FR-013**: 시스템 MUST 시작 밸런스 $5,000, 누적 수익 $0으로 초기화
- **FR-014**: 시스템 MUST 대시보드에서 현재 밸런스, 누적 수익, 총 베팅 횟수, 승률 표시
- **FR-015**: 시스템 MUST 입력값 유효성 검증 (확률 0~1 범위)

### Key Entities

- **Sport**: 스포츠 타입 (NBA, NHL, MLB), 각 스포츠에 속한 팀 목록 보유
- **Team**: 팀 정보 (팀 이름, 소속 스포츠)
- **BetType**: 베팅 타입 (code: SPREAD_PLUS/SPREAD_MINUS/OVER/UNDER, name: +핸디캡/-핸디캡/오버/언더)
- **Bet**: 개별 베팅 기록 (스포츠, 팀A, 팀B, 베팅대상팀(A/B), 베팅타입, P_agent, P_market, Δp(예측에지), 추천금액, 실제베팅금액, 결과(1/0), Δr(실현에지), 수익/손실, 생성일시)
- **Balance**: 사용자 밸런스 상태 (현재금액, 시작금액, 누적수익)
- **EdgeAnalysis**: 에지 분석 집계 (분석레벨(팀별/베팅타입별/전체), 팀명, 베팅타입, 총베팅수, 평균Δp, 평균Δr, 오차(Δp-Δr))

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자가 예측 입력부터 베팅 추천까지 30초 이내에 완료 가능
- **SC-002**: 모든 베팅 기록이 100% 정확하게 저장되고 복구 가능
- **SC-003**: 예측 에지(Δp) 및 실현 에지(Δr) 계산 정확도 100%
- **SC-004**: 팀별 에지 분석이 해당 팀 10회 이상 베팅 시 자동 제공
- **SC-007**: 전체 포트폴리오 에지 분석이 총 10회 이상 베팅 시 자동 제공
- **SC-005**: 대시보드 로딩 시 현재 밸런스와 누적 수익이 2초 이내 표시
- **SC-006**: 3개 스포츠(NBA, NHL, MLB)의 전체 팀 데이터 제공

## Assumptions

- 베팅 수익 계산 시 단순 승패 기준 (승리 시 베팅금액만큼 수익, 패배 시 베팅금액 손실) 가정
- 실현 에지(Δr)는 개별 베팅의 `Result(1 or 0) - P_market`으로 계산, 팀별/전체는 평균값
- 팀 데이터는 현재 시즌 기준 정규 리그 팀 목록
- 동시 접속 사용자는 1명 (개인용 시스템)
- 데이터는 로컬 저장 (별도 서버 불필요)
